КАК ВЫЛОЖИТЬ САЙТ НА GITHUB PAGES И ПОДКЛЮЧИТЬ LADOGATRAVEL.RU
==============================================================

Что в архиве
------------
index.html    — сам сайт
404.html      — страница «не найдено»
CNAME         — адрес домена (ladogatravel.ru), не удаляйте
robots.txt    — разрешает поисковикам индексировать сайт
sitemap.xml   — карта сайта для Яндекса и Google
img/          — папка для фото (см. файл внутри)


1. Фото
-------
Ваши фото уже уменьшены и лежат в папке img (hero.jpg — обложка, g01…g08 — галерея).
Данные о месте съёмки (GPS) из файлов удалены.
Чтобы заменить фото — загрузите на GitHub файл с тем же именем, он заменит старый.
Чтобы добавить новое — пришлите его мне, или скопируйте в index.html строку <figure>…</figure> из галереи и поменяйте имя файла и подпись.


2. Создайте аккаунт и репозиторий на GitHub
-------------------------------------------
1) Зарегистрируйтесь на github.com (бесплатно).
2) Справа вверху «+» → New repository.
3) Repository name: ladogatravel. Выберите Public (на бесплатном тарифе сайт работает только из публичного репозитория).
4) Нажмите Create repository.


3. Загрузите файлы
------------------
1) В новом репозитории нажмите «uploading an existing file» (или Add file → Upload files).
2) Перетащите ВСЕ файлы и папку img из архива (распакуйте его сначала). index.html должен лежать в корне, не во вложенной папке.
3) Внизу нажмите Commit changes.


4. Включите GitHub Pages
------------------------
1) Settings (вкладка репозитория) → слева Pages.
2) Source: Deploy from a branch. Branch: main, папка / (root). Save.
3) Через 1–2 минуты сайт откроется по адресу вида https://ВАШ_ЛОГИН.github.io/ladogatravel/
   Проверьте, что всё на месте.


5. Подключите домен ladogatravel.ru
-----------------------------------
Сначала узнайте, где зарегистрирован домен (reg.ru, nic.ru, Timeweb, Beget и т. п. — придёт в письмах при покупке, или проверьте на whois.ru).
Если домен покупали ЧЕРЕЗ ТИЛЬДУ — его сначала нужно перенести к обычному регистратору (у reg.ru есть инструкция «Как передать домен с Tilda»).

В панели регистратора откройте DNS-записи домена и сделайте так:

  Тип   Имя (хост)   Значение
  A     @            185.199.108.153
  A     @            185.199.109.153
  A     @            185.199.110.153
  A     @            185.199.111.153
  CNAME www          ВАШ_ЛОГИН.github.io

Старые записи A для @ и CNAME для www (которые вели на Тильду) удалите.

Затем на GitHub: Settings → Pages → Custom domain: впишите ladogatravel.ru → Save.
DNS обновляется от 15 минут до суток. Когда проверка пройдёт, поставьте галочку Enforce HTTPS.


6. Чтобы сайт нашли в поиске
----------------------------
1) Яндекс Вебмастер (webmaster.yandex.ru) → Добавить сайт → https://ladogatravel.ru
   Способ подтверждения «Мета-тег»: скопируйте строку вида
   <meta name="yandex-verification" content="...">
   и вставьте её в index.html на место комментария «Яндекс Вебмастер» (в самом верху файла).
   Загрузите обновлённый index.html на GitHub и нажмите «Проверить».
   В Вебмастере: Индексирование → Файлы Sitemap → добавьте https://ladogatravel.ru/sitemap.xml
2) Яндекс Бизнес (yandex.ru/sprav) — заведите бесплатную карточку: причал на карте, фото, телефон, ссылка на сайт.
   После каждой прогулки просите гостей оставить там отзыв.
3) На Тильде снимите публикацию старого сайта или поставьте на нём ссылку на новый — чтобы в поиске не было двух сайтов с одинаковым текстом.


7. Как поменять цены и тексты
-----------------------------
На GitHub откройте index.html → значок карандаша (Edit) → найдите текст (Ctrl+F), например «10 000», исправьте → Commit changes.
Через минуту изменения будут на сайте.
Цены стоят в трёх местах: в шапке («от 10 000 ₽») и в карточках маршрутов (цена за катер и «с человека»).
